# Italy Travel 2026

Mobile-friendly itinerary for our Italy trip.

## Website

The site is built as a static GitHub Pages site. The entry file is `index.html`.

## Structure

- `index.html` — loads the itinerary sections
- `content-1.html` — Rome
- `content-2.html` — Florence / Pisa / Cinque Terre
- `content-3.html` — Venice / Dobbiaco / Val di Funes
- `content-4.html` — Ortisei / Milan / return trip
- `styles.css` — responsive styling
- `app.js` — countdown, today highlighting, and Google Maps links
